provider "aws" {
  region = "ap-south-1"
}

# ---------------- VPC ----------------
resource "aws_vpc" "main" {
  cidr_block = "10.0.0.0/16"
}

# ---------------- Subnets ----------------
resource "aws_subnet" "subnet1" {
  vpc_id                  = aws_vpc.main.id
  cidr_block              = "10.0.1.0/24"
  availability_zone       = "ap-south-1a"
  map_public_ip_on_launch = true
}

resource "aws_subnet" "subnet2" {
  vpc_id                  = aws_vpc.main.id
  cidr_block              = "10.0.2.0/24"
  availability_zone       = "ap-south-1b"
  map_public_ip_on_launch = true
}

# ---------------- Internet Gateway ----------------
resource "aws_internet_gateway" "igw" {
  vpc_id = aws_vpc.main.id
}

# ---------------- Route Table ----------------
resource "aws_route_table" "rt" {
  vpc_id = aws_vpc.main.id

  route {
    cidr_block = "0.0.0.0/0"
    gateway_id = aws_internet_gateway.igw.id
  }
}

resource "aws_route_table_association" "a1" {
  subnet_id      = aws_subnet.subnet1.id
  route_table_id = aws_route_table.rt.id
}

resource "aws_route_table_association" "a2" {
  subnet_id      = aws_subnet.subnet2.id
  route_table_id = aws_route_table.rt.id
}

# ---------------- Security Group ----------------
resource "aws_security_group" "sg" {
  vpc_id = aws_vpc.main.id

  ingress {
    from_port   = 80
    to_port     = 80
    protocol    = "tcp"
    cidr_blocks = ["0.0.0.0/0"]
  }

  ingress {
    from_port   = 22
    to_port     = 22
    protocol    = "tcp"
    cidr_blocks = ["0.0.0.0/0"]
  }

  egress {
    from_port   = 0
    to_port     = 0
    protocol    = "-1"
    cidr_blocks = ["0.0.0.0/0"]
  }
}

# ---------------- EC2 Instance 1 ----------------
resource "aws_instance" "web1" {
  ami           = "ami-01b40e1bcccae197a"
  instance_type = "t3.micro"
  subnet_id     = aws_subnet.subnet1.id

  vpc_security_group_ids = [aws_security_group.sg.id]

  user_data = <<-EOF
              #!/bin/bash
              yum update -y
              yum install -y httpd

    Name = "Web-Server-1"

Recipe 21: Managing Infrastructure Dependencies with Terraform 
Objective 
Understand resource dependencies in Terraform. 
Assignment Task 
Create infrastructure with dependent resources. 
Guidelines / Steps 
1. Create resources such as: 
o VPC 
o Subnet 
o EC2 instance 
2. Use implicit or explicit dependencies. 
3. Configure Terraform resource relationships. 
4. Run: 
terraform plan 
5. Apply configuration. 
6. Verify creation order of resources. 
Expected Outcome 
Resources should be created in the correct order.


main.tf:-

provider "aws" {
  region = "ap-south-1"
}

# ---------------- VPC ----------------
resource "aws_vpc" "v" {
  cidr_block = "10.0.0.0/16"

  tags = {
    Name = "VPC"
  }
}

# ---------------- Subnet ----------------
resource "aws_subnet" "s" {
  vpc_id     = aws_vpc.v.id   #  Implicit dependency (uses VPC ID)
  cidr_block = "10.0.1.0/24"

  tags = {
    Name = "Subnet"
  }
}

# ---------------- Security Group ----------------
resource "aws_security_group" "sg" {
  vpc_id = aws_vpc.v.id

  depends_on = [aws_vpc.v]   #  Explicit dependency (manual control)

  tags = {
    Name = "SG"
  }
}

# ---------------- EC2 ----------------
resource "aws_instance" "ec2" {
  ami           = "ami-01b40e1bcccae197a"
  instance_type = "t3.micro"

  subnet_id              = aws_subnet.s.id   # Implicit dependency (Subnet)
  vpc_security_group_ids = [aws_security_group.sg.id]  #  Implicit dependency (SG)

  tags = {
    Name = "EC2"
  }
}

Recipe 23: Scaling Infrastructure using Terraform 
Objective

Guidelines / Steps

main.tf:-

}

  desired_capacity = 2
  min_size         = 1
  max_size         = 4

  vpc_zone_identifier = [
    "subnet-0e6b911e553a797f4",ye
    "subnet-03cb6982dd2d426a3"
  ]

    id      = aws_launch_template.web_template.id
    version = "$Latest"
  }

workflow:-

Terraform apply
        ↓
ASG creates 2 EC2 instances (desired=2)
        ↓

        ↓

        ↓
If load decreases → removes EC2 (min 1)
